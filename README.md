# 🏏 Cricket Player Performance Dashboard

## 📊 Project Overview

This project is an Excel-based Cricket Player Performance Dashboard created to analyze and visualize cricket player statistics.

The dashboard provides a simple and interactive way to explore batting performance and compare different players based on their key statistics.

## 🎯 Objectives

- Analyze cricket player performance
- Identify top run scorers
- Compare batting averages
- Analyze century makers
- Identify players with the highest individual scores
- Present important statistics using an interactive dashboard

## 📌 Dashboard Features

The dashboard includes:

- Total Players
- Total Matches
- Total Runs
- Total Centuries
- Total Half-Centuries
- Highest Individual Score
- Top 10 Run Scorers
- Top 10 Batting Average
- Top 10 Century Makers
- Top 10 Highest Individual Scores
- Player-wise performance comparison

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Filtering & Visualization

## 📈 Key Visualizations

The dashboard contains multiple charts to visualize:

- Top Run Scorers
- Batting Average
- Century Makers
- Highest Individual Scores
- Player-wise comparison of batting statistics
